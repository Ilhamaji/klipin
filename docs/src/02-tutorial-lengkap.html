3. Menyiapkan Database

Opsi A — Supabase (disarankan)

  1. Buat project baru di supabase.com.
  2. Buka SQL Editor, tempel seluruh isi database/schema.sql, lalu Run.
  3. Buka Project Settings → Database dan catat:
    • Host pooler, misalnya aws-1-ap-southeast-1.pooler.supabase.com
    • Port 6543 (transaction pooler)
    • User postgres.<project-ref>
    • Password database
  4. Isi kredensial yang sama di backend/.env dan ai-service/.env.

Opsi B — PostgreSQL lokal

createdb klipin
psql -d klipin -f database/schema.sql

Lalu di backend/.env:

DB_HOST=localhost
DB_PORT=5432
DB_SSL=false

Dan di ai-service/.env gunakan URL penuh:

DATABASE_URL=postgresql+psycopg2://postgres:password@localhost:5432/klipin?sslmode=disable

Verifikasi tabel

psql -d klipin -c "\dt"

Harus muncul: users, notes, queries, articles, saved_articles.

Isi skema (ringkas)

users(user_id PK, username UNIQUE, password, created_at, updated_at)
notes(id PK, user_id FK, title, contents, created_at, updated_at)
queries(id PK, user_id FK, query_text, embedding JSON,
        model_comparison JSON, created_at)
articles(id PK, query_id FK, title, url, abstract, authors JSON,
         year, subject, jenjang, relevance_score, confidence, created_at)
saved_articles(id PK, user_id FK, article_id FK, created_at,
               UNIQUE(user_id, article_id))

Backend tidak membuat tabel otomatis. Jika skema belum dijalankan, login akan gagal dengan error relasi users tidak ditemukan. AI service hanya menambahkan kolom model_comparison bila belum ada.

    },

  2. Login; pastikan cookie auth_token ada dan halaman utama terbuka.

9.2 Kontrak data yang wajib dipenuhi

Fungsi provider harus mengembalikan list of dict dengan field berikut:

FieldTipeDipakai untuk
titlestringarticles.title
linkstring URLarticles.url dan input ringkasan

Jangan mengubah nama field. router.py membaca item["title"], item["link"], item["abstract"], item["authors"], dan item["year"]. Jika provider baru memakai nama lain, map dulu di fungsi Anda.

9.3 Contoh lengkap: OpenAlex (gratis, tanpa API key)

Tambahkan fungsi berikut di search_service.py:

import os
import requests

OPENALEX_URL = "https://api.openalex.org/works"


def search_openalex(query: str, embedding_model):
    params = {
        "search": query,
        "per-page": SERPAPI_NUM,
        "mailto": os.getenv("OPENALEX_MAILTO", ""),
    }

    response = requests.get(OPENALEX_URL, params=params, timeout=30)
    if response.status_code != 200:
        raise Exception("Gagal mengambil data dari OpenAlex")

    results = []
    for work in response.json().get("results", []):
        abstract = ""
        inverted = work.get("abstract_inverted_index") or {}
        if inverted:
            words = []
            for word, positions in inverted.items():
                for position in positions:
                    words.append((position, word))
            abstract = " ".join(word for _, word in sorted(words))

        authors = [
            item.get("author", {}).get("display_name", "")
            for item in work.get("authorships", [])
        ]

        results.append({
            "title": work.get("display_name") or "",
            "link": (
                (work.get("primary_location") or {}).get("landing_page_url")
                or work.get("doi")
                or ""
            ),
            "abstract": abstract,
            "authors": authors,
            "year": str(work.get("publication_year") or ""),
        })

    return semantic_rerank(query, results, embedding_model)[:SERPAPI_TOP_K]

Ubah router.py:

# dari
from src.services.search_service import search_serpapi
# menjadi
from src.services.search_service import search_openalex

# dari
search_results = search_serpapi(user_query, embedding_model)
# menjadi

Ubah juga label sumber. Di router.py ada dua tempat yang mengembalikan "source": "serpapi" (hasil kosong dan hasil normal); ganti keduanya menjadi "source": "openalex". Blok except yang menyebut SerpAPI juga sebaiknya disesuaikan agar pesan errornya tidak menyesatkan.

9.4 Contoh: Semantic Scholar

SEMANTIC_URL = "https://api.semanticscholar.org/graph/v1/paper/search"


def search_semantic_scholar(query: str, embedding_model):
    params = {
        "query": query,
        "limit": SERPAPI_NUM,
        "fields": "title,abstract,authors,year,url,openAccessPdf",
    }
    headers = {}
    api_key = os.getenv("SEMANTIC_SCHOLAR_API_KEY")
    if api_key:
        headers["x-api-key"] = api_key

    response = requests.get(
        SEMANTIC_URL, params=params, headers=headers, timeout=30
    )
    if response.status_code != 200:
        raise Exception("Gagal mengambil data dari Semantic Scholar")

    results = []
    for paper in response.json().get("data", []):
        pdf_url = (paper.get("openAccessPdf") or {}).get("url")
        results.append({
            "title": paper.get("title") or "",
            "link": pdf_url or paper.get("url") or "",
            "abstract": paper.get("abstract") or "",
            "authors": [a.get("name", "") for a in paper.get("authors", [])],
            "year": str(paper.get("year") or ""),
        })

    return semantic_rerank(query, results, embedding_model)[:SERPAPI_TOP_K]

9.5 Contoh: Crossref

CROSSREF_URL = "https://api.crossref.org/works"


def search_crossref(query: str, embedding_model):
    params = {
        "query": query,
        "rows": SERPAPI_NUM,
        "mailto": os.getenv("CROSSREF_MAILTO", ""),
    }
    response = requests.get(CROSSREF_URL, params=params, timeout=30)
    if response.status_code != 200:
        raise Exception("Gagal mengambil data dari Crossref")

    results = []
    for item in response.json().get("message", {}).get("items", []):
        titles = item.get("title") or []
        year = ""
        parts = (item.get("published-print") or item.get("published-online") or {}) \
            .get("date-parts") or [[]]
        if parts and parts[0]:
            year = str(parts[0][0])

        authors = [
            " ".join(filter(None, [a.get("given"), a.get("family")]))
            for a in item.get("author", [])
        ]

        results.append({
            "title": titles[0] if titles else "",
            "link": item.get("URL") or "",
            "abstract": item.get("abstract") or "",
            "authors": authors,
            "year": year,
        })

    return semantic_rerank(query, results, embedding_model)[:SERPAPI_TOP_K]

9.6 Hal yang harus diperhatikan

AspekPenjelasan
CacheCache memakai embedding query, bukan nama provider. Setelah mengganti provider, query lama masih bisa mengembalikan hasil lama. Hapus baris queries milik user uji.
Error handlingLempar exception dengan pesan jelas; router mengubahnya menjadi HTTP 502.
Rate limitOpenAlex/Crossref meminta mailto agar masuk polite pool. Semantic Scholar membatasi request tanpa API key.
AbstrakSebagian provider tidak menyediakan abstrak; klasifikasi tetap berjalan dengan judul saja, tetapi akurasi turun.
LinkPrioritaskan URL PDF open access agar ringkasan tidak gagal 422.
TahunPastikan string, bukan integer, agar konsisten dengan kolom varchar(4).
User-AgentBeberapa API memblokir klien tanpa identitas. Tambahkan header yang menyebut aplikasi dan kontak.

9.7 Menguji provider baru

  1. Restart AI service (uvicorn dengan --reload otomatis memuat ulang).
  2. Hapus cache query lama lewat SQL: 
    DELETE FROM queries WHERE user_id = 1;
  3. Panggil langsung: 
    curl.exe -X POST http://localhost:7860/ai/search -H "Content-Type: application/json" -d "{\"query\":\"fotosintesis\",\"user_id\":1}"
  4. Periksa source bernilai provider baru dan setiap artikel punya title, url, year, serta label mapel.
  5. Buka UI dan lakukan pencarian yang sama.

9.8 Checklist

  • Fungsi provider mengembalikan lima field wajib dengan tipe benar.
  • router.py mengimpor dan memanggil fungsi baru.
  • Label source dan pesan error sudah disesuaikan.
  • Env baru ditambahkan ke .env.example dan dokumentasi.
  • Key lama (jika tidak dipakai) dihapus dari env dan tidak lagi diwajibkan.
  • Diuji dengan query yang belum pernah dipakai agar cache tidak menutupi hasil.

10. Mengganti Resolver PDF

Resolver PDF menentukan apakah sebuah URL artikel bisa diubah menjadi file PDF yang bisa diekstrak. Bagian ini yang paling sering menyebabkan error 422.

10.1 Alur saat ini

summarize_from_url(url) → cek cache → _find_pdf_url(url) → validasi application/pdf → _extract_text_from_pdf() → summarize() ke LLM → parse 7 field → simpan cache.

10.2 Fungsi yang perlu diubah

FungsiTanggung jawab
_find_pdf_url(article_url)Menemukan URL PDF dari halaman artikel
_extract_text_from_pdf(pdf_url)Mengunduh PDF, memvalidasi tipe, ekstraksi PyMuPDF
_document_title(doc)Mengambil judul dari metadata atau halaman pertama
summarize_from_url()Orkestrasi + cache

10.3 Menambah pola domain jurnal

Tambahkan cabang di awal _find_pdf_url, sebelum pencarian HTML umum:

def _find_pdf_url(article_url: str) -> str | None:
    headers = {
        "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
    }

    # Pola OJS umum
    if "/article/view/" in article_url:
        candidate = article_url.replace("/article/view/", "/article/download/")
        try:
            test = requests.get(candidate, headers=headers, timeout=10, stream=True)
            if "application/pdf" in test.headers.get("Content-Type", ""):
                return candidate
        except Exception:
            pass

    # Domain dengan pola khusus
    if "jurnal.example.ac.id" in article_url:
        candidate = article_url.rstrip("/") + "/pdf"
        return candidate

    # ... kode lama: cek PDF langsung, a.pdf, link .pdf/download/fulltext ...

10.4 Menambahkan cookie/referer

Sebagian jurnal menolak unduhan tanpa referer atau sesi:

headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
    "Referer": article_url,
    "Cookie": os.getenv("JOURNAL_COOKIE", ""),

Simpan cookie di env, jangan hardcode di source.

10.5 Menyelesaikan DOI ke PDF open access (Unpaywall)

import re

DOI_PATTERN = re.compile(r"10\.\d{4,9}/[-._;()/:A-Za-z0-9]+")


def resolve_pdf_from_doi(article_url: str) -> str | None:
    match = DOI_PATTERN.search(article_url)
    if not match:
        return None

    doi = match.group(0)
    response = requests.get(
        f"https://api.unpaywall.org/v2/{doi}",
        params={"email": os.getenv("UNPAYWALL_EMAIL", "")},
        timeout=15,
    )
    if response.status_code != 200:
        return None

    best = response.json().get("best_oa_location") or {}
    return best.get("url_for_pdf") or best.get("url")

Panggil di _find_pdf_url sebelum fallback HTML:

doi_pdf = resolve_pdf_from_doi(article_url)
if doi_pdf:
    return doi_pdf

10.6 Halaman yang membutuhkan JavaScript (Playwright)

requests + BeautifulSoup tidak mengeksekusi JavaScript. Untuk situs seperti itu:

from playwright.sync_api import sync_playwright


def _resolve_pdf_with_browser(article_url: str) -> str | None:
    with sync_playwright() as p:
        browser = p.chromium.launch()
        page = browser.new_page()
        page.goto(article_url, wait_until="networkidle", timeout=20000)
        href = page.eval_on_selector(
            "a.pdf, a[href$='.pdf'], a[href*='download']",
            "el => el.href",
        )
        browser.close()
        return href

Tambahkan dependensi:

pip install playwright
playwright install chromium

Ukuran image membengkak. Chromium menambah ratusan MB. Di Hugging Face Space, gunakan Dockerfile dan jalankan playwright install --with-deps chromium saat build. Panggil Playwright hanya sebagai fallback, bukan untuk semua URL.

11. Mengganti Model Summarize (LLM)

Model ringkasan diatur di ai-service/src/services/summarize_service.py. Ada dua tingkat perubahan: mengganti nama model di Groq, atau mengganti provider LLM sepenuhnya.

11.1 Parameter saat ini

ItemNilai
Endpointhttps://api.groq.com/openai/v1/chat/completions
Modelopenai/gpt-oss-20b (env GROQ_MODEL)
Temperature0,2
reasoning_effortlow (khusus model gpt-oss)
Max output1300 token (env)
Retry3 kali, backoff eksponensial, menghormati Retry-After
Timeout request90 detik

11.2 Cara termudah: ganti model Groq

Tanpa mengubah kode, cukup ubah env:

GROQ_MODEL=openai/gpt-oss-120b

Daftar model tersedia: https://api.groq.com/openai/v1/models dengan header Authorization: Bearer $GROQ_API_KEY.

Pilih model yang mendukung output terstruktur. Ringkasan bergantung pada tujuh label teks. Model kecil tanpa instruksi kuat sering mengembalikan format bebas sehingga parser menghasilkan field kosong.

11.3 Ganti provider OpenAI-compatible

Banyak provider memakai skema request yang sama. Ubah konstanta menjadi env:

LLM_API_URL = os.getenv(
    "LLM_API_URL", "https://api.groq.com/openai/v1/chat/completions"
)
LLM_API_KEY = os.getenv("LLM_API_KEY") or os.getenv("GROQ_API_KEY")
LLM_MODEL = os.getenv("LLM_MODEL", "openai/gpt-oss-20b")

Lalu di summarize():

headers = {
    "Authorization": f"Bearer {LLM_API_KEY}",
    "Content-Type": "application/json",
}

payload = {
    "model": LLM_MODEL,
    "messages": [{"role": "user", "content": prompt}],
    "temperature": 0.2,
    "max_tokens": MAX_OUTPUT_TOKENS,
}

Hapus reasoning_effort jika provider bukan Groq/gpt-oss. Field ini tidak dikenal OpenAI, Gemini, atau Ollama dan dapat menyebabkan error 400.

11.6 Menyesuaikan prompt

  • Pertahankan instruksi “tulis dalam Bahasa Indonesia baku” agar konsisten.
  • Instruksi kesimpulan berbentuk paragraf harus tetap ada; model cenderung membuat poin.
  • Jangan menambah bagian baru tanpa memperbarui parser dan UI.
  • Untuk dokumen non-akademik, tambahkan kalimat bahwa konteks boleh berupa materi ajar.

12. Opsional: Melatih Ulang Model Klasifikasi

Bagian ini hanya diperlukan bila Anda ingin mengganti label atau meningkatkan akurasi. Untuk sekadar menjalankan project, lewati bagian ini.

12.1 Format dataset

Setiap sampel adalah pasangan teks dan label "Mapel - Jenjang":

texts = [
    "Bagaimana cara menghitung luas lingkaran?",
    "Proses fotosintesis pada tumbuhan hijau",
]
labels = [
    "Matematika - SD",
    "Biologi - SMA",
]

12.2 Yang dilakukan skrip

  1. Memuat LaBSE dan mengubah seluruh teks menjadi embedding 768 dimensi.
  2. Melatih empat model: KNN, SVM, Logistic Regression, Random Forest.
  3. Menyimpan model dan label_encoder.pkl ke src/models/.

scripts/train_models.py adalah contoh. Isinya masih memakai enam kalimat contoh dan parameter default. Ganti texts dan labels dengan dataset nyata, lalu sesuaikan hyperparameter.

12.3 Langkah

  1. Siapkan dataset minimal 10 sampel per kelas (idealnya ratusan).
  2. Ganti texts dan labels di skrip; jaga agar setiap label memakai format Mapel - Jenjang dengan pemisah " - ".
  3. Jalankan: 
    cd ai-service
python scripts/train_models.py
  4. Pastikan file berikut diperbarui: model_knn.pkl, model_svm.pkl, model_logreg.pkl, model_randomforest.pkl, label_encoder.pkl.
  5. Sesuaikan threshold per algoritma di clasify_service.py: 
    OPTIMAL_THRESHOLD_PER_ALGO = {
    "knn": 0.59,
    "svm": 0.37,
    "logreg": 0.52,
    "rf": 0.09,
}
  6. Perbarui src/models/model_metadata.json bila Anda menampilkan skor di UI.
  7. Hapus __pycache__ dan restart AI service agar model dimuat ulang.
  8. Uji dengan beberapa kalimat yang tidak ada di dataset.

Satu encoder untuk semua model. Keempat model memakai label_encoder.pkl yang sama. Jangan mencampur encoder dari pelatihan berbeda; urutan kelas harus identik.

12.4 Menambah kelas baru

  • Tambahkan label pada dataset dan latih ulang semua model.
  • Jumlah kelas di model_metadata.json harus diperbarui.
  • Threshold perlu ditinjau ulang karena distribusi probabilitas berubah.
  • UI tidak menyimpan daftar kelas, jadi tidak ada perubahan frontend.

14. Checklist Go-Live

Konfigurasi

  • Semua .env berisi kredensial asli dan tidak ikut ter-commit.
  • JWT_SECRET acak dan berbeda antara lokal dan produksi.
  • FASTAPI_URL menunjuk ke AI service produksi, bukan localhost.
  • NEXT_PUBLIC_API_URL menunjuk ke backend produksi dengan path /api.
  • DB_SSL=true untuk Supabase; false hanya untuk PostgreSQL lokal.

Fungsi

  • Register, login, logout, dan proteksi route berjalan.
  • Pencarian mengembalikan artikel dengan label mapel dan jenjang.
  • Cache query bekerja: query serupa tidak memanggil provider lagi.
  • Ringkasan menghasilkan tujuh field dan dapat disimpan sebagai catatan.
  • Edit catatan benar-benar mengubah isi di database.
  • Library: simpan, tampil di Materi, hapus, dan hapus kedua menghasilkan 404.
  • Histori dapat dilihat dan dihapus.

Keamanan

  • Secret lama yang pernah bocor sudah dirotasi.
  • CORS dibatasi ke origin frontend.
  • Rate limit aktif untuk endpoint mahal (search, summarize).
  • AI service tidak dapat diakses publik tanpa pembatas.
  • Token uji coba dan akses database dicabut setelah selesai.

Operasional

  • Health check dipantau (/health, /api/ai/ready).
  • Log mencatat durasi pencarian, ringkasan, dan error provider.
  • Backup database terjadwal.
  • Kuota SerpAPI dan Groq dipantau.
  • Rencana fallback bila provider utama down.
